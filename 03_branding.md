## 2. СЛОГАН — тестируем варианты

### Кандидаты (нужно выбрать 1 RU + 1 EN)

| #   | Слоган                                                                | Почему                     | Для какой аудитории       |
| --- | --------------------------------------------------------------------- | -------------------------- | ------------------------- |
| 1   | **«Суфлёр для твоих созвонов»**                                       | Просто и ясно              | Все                       |
| 2   | **«ИИ-крастер на все руки»**                                          | Игра слов, меметичность    | RU, молодёжь              |
| 3   | **«Твой невидимый союзник в любом звонке»**                           | Акцент на скрытность       | Продажники, переговорщики |
| 4   | **«Получи оффер. Закрой сделку. Сдай отчёт.»**                        | Конкретика + результат     | Все                       |
| 5   | **«Умнее на созвоне. Увереннее на свидании. Подкованнее на лекции.»** | **v2:** три аудитории      | Все                       |
| 6   | **«Every call, mastered.»**                                           | По-английски звучит сильно | EN-аудитория              |
| 7   | **«Your AI copilot for live conversations.»**                         | Скучно, но понятно         | EN-аудитория              |
| 8   | **«Hear. See. Whisper.»**                                             | Три глагола = три фичи     | EN, минималистично        |
| 9   | **«Hear it. See it. Know what to say.»**                              | Сторителлинг               | EN-маркетинг              |

### Метод выбора

1. Выпиши топ-3 на стикерах (1 RU + 1 EN отдельно)
2. Покажи 10 знакомым (3 программистам, 3 продажникам, 4 «обычным»)
3. Спроси: «Что тебе сразу представилось?»
4. Выбери тот, на который чаще отвечают правильно

### Мой рекомендованный набор (v2)

- 🇷🇺 **Основной:** «Суфлёр для твоих созвонов»
- 🇷🇺 **Дерзкий (для соцсетей):** «Мастер-Крастер на все руки»
- 🇺🇸 **Основной:** «Your AI copilot for live calls»
- 🇺🇸 **Короткий (для лого):** «Hear. See. Whisper.»

## 3. ЛОГОТИП — генерация и доработка

### Уже есть промпт

Файл `logo_prompt.md` содержит готовый промпт:

> A futuristic minimalist tech logo for a desktop software named "Quistant". The logo is a geometric letter "Q" formed by the silhouette of a smart cyber-parrot sitting in profile. The body and head of the parrot create the perfect circle of the "Q", while its long, sharp, aerodynamic tail feathers elegantly extend to form the lower tail of the letter "Q". The parrot has a subtle glowing cybernetic eye. Dark mode aesthetic, neon blue and electric green colors, clean vector lines, smooth gradients, modern software icon style, transparent background.

### Как использовать промпт

#### Вариант А: Через Midjourney / Flux

1. Зарегистрируйся в [Midjourney](https://midjourney.com) или используй бесплатный [Flux через Replicate](https://replicate.com/black-forest-labs/flux-schnell)
2. Вставь промпт, добавь `--ar 1:1 --style raw --v 6`
3. Сгенерируй 4 варианта, выбери лучший
4. Апскейль через [upscale.media](https://upscale.media) до 2048×2048
5. Передай дизайнеру для **векторизации в SVG** (важно для иконки приложения!)

#### Вариант Б: Через дизайнера

1. Отправь промпт дизайнеру + референсы (см. ниже)
2. Попроси 3 варианта в SVG
3. Выбери один, попроси доработать

### Референсы для дизайнера

Скинь эти ссылки для вдохновения:

- [Linear](https://linear.app) — минимализм, чёткие линии
- [Raycast](https://raycast.com) — иконка приложения
- [Vercel](https://vercel.com) — типографика и тёмная тема
- [Final Round AI](https://finalroundai.com) — как делают конкуренты
- [Ecoute](https://github.com/SevaSk/ecoute) — на чём ты базируешься

### Что должно быть в финальном лого

- [ ] **SVG** (векторный, для масштабирования)
- [ ] **PNG 2048×2048** (для сайта и маркетинга)
- [ ] **PNG 512×512** (для постов)
- [ ] **ICO 256×256** (для иконки Windows-приложения) — можно сделать на [convertico.com](https://convertico.com)
- [ ] **Favicon 32×32** (для сайта)
- [ ] **Apple Touch Icon 180×180** (на будущее)
- [ ] **Лайт-вариант** (для белого фона, если будет светлая тема)

### Где будет использоваться

- Иконка приложения (в трее, на рабочем столе, в окне «Программы и компоненты»)
- Логотип на сайте (header, favicon)
- Telegram-канал (аватарка)
- YouTube (аватарка и превью)
- Email-рассылки
- Скриншоты продукта (для маркетинга)
- Печати на футболках (если дойдёт до мерча)

## 4. ЦВЕТОВАЯ ПАЛИТРА

### Базовая (dark mode по умолчанию)

| Роль                     | Цвет                 | HEX       | Когда используется                |
| ------------------------ | -------------------- | --------- | --------------------------------- |
| **Background primary**   | Глубокий тёмно-синий | `#0A0E1A` | Основной фон                      |
| **Background secondary** | Чуть светлее         | `#141825` | Карточки, окна                    |
| **Background tertiary**  | Ещё светлее          | `#1E2335` | Ховер, активные элементы          |
| **Accent primary**       | Неоновый cyan        | `#00D9FF` | Главные кнопки, активные элементы |
| **Accent secondary**     | Electric green       | `#39FF14` | Успех, «работает», статус         |
| **Warning**              | Жёлтый               | `#FFD700` | Предупреждения                    |
| **Danger**               | Красный              | `#FF3366` | Ошибки, лимиты                    |
| **Text primary**         | Белый                | `#FFFFFF` | Основной текст                    |
| **Text secondary**       | Светло-серый         | `#A0A8B8` | Вторичный текст                   |

### Альтернативная палитра (если не зайдёт cyan+green)

- Фиолетовый `#A855F7` + розовый `#EC4899` (в стиле Linear/Notion)
- Оранжевый `#FF6B35` + голубой `#4ECDC4` (тёплая + холодная)

### Light mode (на будущее)

- Background: `#FFFFFF` / `#F8F9FB`
- Text: `#0A0E1A`
- Accent: те же cyan/green

## 6. ТОН ГОЛОСА (Tone of Voice)

### Кто мы

**Дерзкий, но дружелюбный технический помощник.** Не корпоративный, не пафосный.

### Как говорим

| ✅ Да                                                | ❌ Нет                                                              |
| --------------------------------------------------- | ------------------------------------------------------------------ |
| «Подключи папку — Куистант сам всё проиндексирует»  | «Воспользуйтесь возможностью автоматической индексации документов» |
| «Zoom не увидит ни окна, ни рамку»                  | «Обеспечивается конфиденциальность пользовательского интерфейса»   |
| «Получи оффер за 990 ₽»                             | «Тарифный план открывает возможности»                              |
| «Глючит? Напиши — починим за день»                  | «В случае возникновения трудностей обратитесь в службу поддержки»  |
| «Эй, Куистант, запомни — теперь обсуждаем зарплату» | «Используйте голосовую команду для смены контекстной области»      |

### Эмодзи в коммуникациях

- В Telegram: умеренно (1–2 на пост)
- В UI: только функциональные (статус, иконки)
- В маркетинге: можно больше для запоминания

### Запрещено

- Канцелярит («осуществление», «в целях», «данный продукт»)
- Обещания, которые нельзя выполнить («100% гарантия оффера»)
- Унижение конкурентов (лучше показывать свои преимущества)
- **v2:** давление на стыд («ты тупой и без ИИ не выживешь») — мы помогаем, а не пугаем

# Куистант / Quistant — Brand Book

## Имя
- RU: Куистант
- EN: Quistant
- Произношение: «Кви-стант»

## Слоган
- RU: Суфлёр для твоих созвонов
- EN: Your AI copilot for live calls

## Логотип
- [прикрепить файлы]
- Минимальный размер: 32px (favicon), 64px (UI), 256px (сайт)
- Отступы: минимум 16px от других элементов

## Цвета
[палитра из пункта 4]

## Шрифты
[из пункта 5]

## Тон голоса
[из пункта 6]

## Когда нельзя использовать
- На тёмном фоне не использовать тёмный логотип
- Не растягивать / не сжимать непропорционально
- Не менять цвета акцентов
- Не ставить рядом с лого конкурентов

## Расширения ЦА (v2)
- Не только собесы, но и свидания, лекции, подкасты
- «Ассистент без собеседника» = вторая равноправная ЦА
