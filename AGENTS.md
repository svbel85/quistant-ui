# AGENTS.md — проектные инструкции для Kilo

## 1. Нейминг сессий

В **самом первом ответе** ассистента в каждой новой сессии в этом проекте — до любого другого текста или вызова инструментов — выведи ровно одну строку:

<session_title>Короткое название на 3-6 слов</session_title>

Правила:
- Тему бери из первого сообщения пользователя.
- Язык названия — **как у пользователя** (русский запрос → русское название, английский → английское).
- Без кавычек, без префикса «Title:», без точки в конце.
- На последующих ходах тег **не повторяй**.
- Если тема резко сменилась — можно один раз выдать обновлённый тег с коротким пояснением сразу после него.

Зачем это нужно: обходной путь для регрессии `kilo-auto/small` — встроенный авто‑неймер сломан, поэтому задаём имя сессии вручную через этот тег.

## 2. Сообщения коммитов

Когда ассистент формирует коммит в этом проекте, придерживайся следующих правил.

**Заголовок (subject, первая строка):**
- Строго на **английском**.
- Формат: `<тип>(<область>): <краткое действие в повелительном наклонении, строчными, без точки в конце>`.
- Примеры: `feat(theme): add glass surface tokens`, `fix(auth): resolve token refresh loop`.

**Тело коммита (body, после пустой строки):**
- Строго на **русском**.
- Объясняй ЧТО было изменено и ПОЧЕМУ, избегая банального пересказа кода.
- Короткие абзацы или маркеры списка (`-`).
- Если добавляются переменные, параметры или перечисляются компоненты — оформляй их понятным списком.

**Структура ответа:**
- Выдавай **только** текст коммита (заголовок, пустая строка, тело на русском) — без вводных слов, пояснений и оформления в кавычки.
