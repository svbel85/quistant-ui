Providers & Keys byok - stored locally encrypted
Keys are stored in the OS keychain (Windows Credential Manager). They never leave this machine. Quistan’s proxy uses them only to forward requests. Edit the base URL to point at a self-hosted OpenAI-compatible endpoint (Ollama, vLLM, LM Studio, custom proxy).

Memory
How Quistan remembers what you teach it. Pick the brain model, run it on GPU if you have one, and rebuild the memory when files change.
Active Model the brain that remembers
Quistan turns every chunk of text into a vector using a local embedding model. The vector store (ChromaDB) then finds the closest chunks when you ask a question. Pick the model that fits your hardware and quality needs.
