# partials/floating-settings/

Вкладки настройки плавающих окон и каркас левого сайдбара.

- `windows-list.html` — левый сайдбар со списком плавающих окон
  (данные подгружаются из `data/windows.json`).
- `tab-identity.html` — отображаемое имя и Accent color.
- `tab-behavior.html` — модель (Fast / Heavy), system prompt,
  Internet search, длина ответа (W).
- `tab-sources.html` — Replies (R), Knowledge bases, Chunks (C).
- `tab-window.html` — пресет размера окна и угол спавна.
- `tab-shortcuts.html` — хоткей переключения, нижний ввод,
  pin (always-on-top).
