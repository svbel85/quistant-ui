# partials/main-window/

Компоненты главного окна:

- `header.html` — шапка с заголовком сессии и управляющими элементами.
- `chat-feed.html` — лента сообщений и карточки подсказок.
- `input-bar.html` — поле ввода и кнопки отправки.
- `bottom-status.html` — нижний статус-бар (состояние, токены, индикаторы).
