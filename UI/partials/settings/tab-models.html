Providers & Keys byok - stored locally encrypted
Keys are stored in the OS keychain (Windows Credential Manager). They never leave this machine. Quistan’s proxy uses them only to forward requests. Edit the base URL to point at a self-hosted OpenAI-compatible endpoint (Ollama, vLLM, LM Studio, custom proxy).
