# partials/settings/

Изолированные вкладки окна параметров (`settings.html`).

Каждая вкладка — отдельный HTML-фрагмент, который загружается в
`<main id="tab-content">` через `js/settings.js` при старте страницы.

- `tab-general.html`
- `tab-account.html`
- `tab-models.html`
- `tab-memory.html`
- `tab-audio.html`
- `tab-capture.html`
- `tab-shortcuts.html`
- `tab-notifications.html`
- `tab-privacy.html`
- `tab-updates.html`
- `tab-advanced.html`
- `dev-panel.html` — служебная панель заметок (вне вкладок)
