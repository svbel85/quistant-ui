# Архитектура и структура папки UI

В этом каталоге собраны все интерфейсные модули, стили, ресурсы и тестовые данные проекта. Интерфейс разделен на модульные компоненты (партиалы), изолированные CSS-слои и JSON-данные, чтобы избежать монолитных HTML-файлов и ускорить разработку через ИИ-ассистентов.

---

## Дерево каталогов

```text
UI/
├── assets/                  # Графика, иконки и шрифты
│   └── textures/            # Фоновые текстуры и подложки тем (.png, .svg)
│
├── css/                     # Изолированные таблицы стилей
│   ├── base.css             # Сброс стилей, типографика, общие стили окон
│   ├── layout.css           # Главные сетки (Grid/Flex), скроллбары, шторки
│   ├── themes.css           # Переменные палитр для тем (Obsidian, Midnight...)
│   ├── settings.css         # Стили окна настроек
│   ├── floating.css         # Стили всплывающих окон и их конфигуратора
│   └── panels.css           # Стили пульта управления и селектора баз знаний
│
├── data/                    # Мок-данные (JSON) для отвязки верстки от текстов
│   ├── feed.json            # Сообщения чата и карточки подсказок
│   ├── knowledge.json       # Список источников баз знаний (RAG)
│   └── windows.json         # Список сессий и пресетов плавающих окон
│
├── js/                      # Клиентская логика макетов
│   ├── main.js              # Сборка окон, переключение шторок и боковых панелей
│   ├── render.js            # Отрисовка шаблонов из JSON-данных
│   └── theme-switcher.js    # Переключение тем через атрибут data-theme
│
├── partials/                # Модульные фрагменты разметки (HTML)
│   ├── main-window/         # Элементы главного экрана (шапка, чат, ввод, статус)
│   ├── drawers/             # Выдвижные шторки (Knowledge, Sessions, Floating)
│   ├── settings/            # Вкладки окна настроек (General, Account, Shortcuts...)
│   ├── floating-settings/   # Вкладки конфигурации окон (Identity, Behavior...)
│   ├── control/             # Блоки пульта управления (кнопки, микрофон)
│   └── kb/                  # Компоненты выбора баз знаний (поиск, список)
│
├── Sourse_1/                # Исходные монолитные файлы (архив / резервная копия)
├── themes_referense/        # Исходные макеты тем для сверки цветов и палитр
│
├── index.html               # Каркас главного окна приложения
├── settings.html            # Каркас окна общих настроек
├── floating_windows_settings.html # Каркас настройки плавающих окон
├── floating_window.html     # Каркас отдельного мини-окна подсказок
├── control_panel.html       # Каркас пульта управления с записью
└── kb_picker.html           # Каркас окна выбора баз знаний
