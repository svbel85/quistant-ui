Когда придёт запрос «отследить изменения после этого коммита»:

```bash
# 1. Что изменилось с момента снапшота
git diff 686f79a --stat
git diff 686f79a --name-only

# 2. Что нового в каждом файле (выжимка)
git log 686f79a..HEAD --oneline
```

Затем вносить новые пункты в `00_summary_vs_roadmap.md` в раздел «**Что НОВОГО изменилось после снапшота**», не ломая старую структуру.
