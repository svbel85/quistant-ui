Quistan · быстрый ответ · 14:06:33
RLS в 1С — где тормозит и что с этим делать
  • RLS накладывается как доп. условие в ГДЕ к каждой виртуальной таблице — запрос выполняется дольше
  • Для отчётов используй ПривилегированныйРежим с проверкой безопасности
  • Кешируй результаты в РегистрыСведений с обновлением по подписке на события
  • Оптимизируй шаблоны RLS — никаких вложенных подзапросов в ГДЕ

Замер производительности запросов в 1С
  1. ЗамерПроизводительности из конфигуратора — самый простой способ
  2. В консоли запросов: ПоказатьВременнуюТаблицу + замер SQL-трассы

  4. ЦУП (Центр управления производительностью) для серьёзных случаев
