## 🎯 Главная суть «Куистанта» (v2)

### Что это такое

**«Куистант»** — это **десктопный карманный гений для ЛЮБОГО живого разговора в интернете**. Это не «помощник для собесов». Это **«быть умнее, начитаннее, обаятельнее и подготовленнее в любом диалоге — и без диалога тоже»**.

Он работает поверх Zoom, Teams, Google Meet, Telegram-звонков, сайтов знакомств, любых программ на Windows. Перехватывает звук из системы + микрофон, ловит скриншоты из зафиксированной области экрана, склеивает это с твоей локальной базой знаний (Markdown-документами) и **в реальном времени выдаёт тактические подсказки** в плавающих окнах поверх звонка.

**Каждое плавающее окно «помнит» свой контекст:** при клике на любую реплику в ленте окно подтягивает N последних реплик до неё (включая саму) и перегенерирует ответ. Количество реплик настраивается в каждом окне отдельно (по умолчанию 10). Если окно не должно реагировать на клики — переключатель «Не переписывать» (= бывшая заморозка). Никаких слайсов, никакой нарезки диалога — просто перемотка с автообновлением.

**v2-дополнение:** Куистант также работает **без собеседника** — слушает видео на YouTube, подкаст, лекцию, фильм. Помогает делать конспекты, отвечать на каверзные вопросы лектора, переводить иностранную речь, анализировать интервью экспертов. Реплика, набранная с клавиатуры, становится полноценной репликой `speaker="user"` — как будто ты говоришь это в живом диалоге.

### Главная мысль

> **Большинство людей стесняются быть «недостаточно умными» на собеседованиях, рабочих встречах, свиданиях, в незнакомых чатах, на лекциях. Куистант снимает этот страх — ты всегда можешь подключиться к разговору (или к учёбе) и выглядеть подготовленным.**

### Что он буквально делает за тебя

1. **Слушает** реплики — твои (микрофон) и собеседника (системный звук через WASAPI loopback)
2. **Транскрибирует** их в текст через Whisper (локально или API)
3. **Определяет спикеров** — кто говорит, ты или собеседник
3. **Перемотка реплик** — клик на любую реплику → каждое окно подтягивает свои N реплик до неё и обновляется
4. **Ловит скриншоты** из рамки, которую ты один раз выделил вокруг экрана собеседника (по одному хоткею)
6. **Принимает текст с клавиатуры** как полноценную реплику (режим «без собеседника»)
7. **Подключает твою RAG-базу** — папки с Markdown (резюме, скрипты, документация, заметки)
8. **Отправляет всё это** в LLM (OpenAI / Anthropic / OpenRouter / свой ключ)
9. **Показывает ответ** в плавающем окне поверх Zoom — пока ты продолжаешь говорить
10. **Прячется от захвата экрана** — собеседник физически не видит ни окна, ни рамку

### Для кого и какие боли решает

> **Куистант полезен ЛЮБОМУ человеку, который говорит с другими людьми в интернете ИЛИ потребляет контент в одиночку.**

10 больших сегментов + «ассистент без собеседника» — подробно в `14_user_personas.md`.

## 🎯 Ключевые принципы (как НЕ проебать проект) — v2

1. **Сначала дизайн-система, потом код.** Шаг 0 из `04_design_system.md`: дизайн-система + 12 экранов в Figma. Шаг 4 (подключение ИИ) — в самом конце.
2. **Mock-сервис с первого дня.** `auth_service.py` сразу пишем как заглушку, чтобы потом не переписывать UI. Вся логика лимитов идёт через него.
3. **Двойная SQLite с первого дня.** `app_state.db` (оперативная) + `knowledge_base.db` (RAG) — две независимые базы.
4. **Безопасность продаётся отдельно.** Скрытность от захвата (WDA_EXCLUDEFROMCAPTURE) — это маркетинговая фича. Если Zoom её спалит — продукт мёртв.
5. **Крипта-оплата с самого начала.** Cryptomus подключаем на Фазе 5, чтобы к моменту запуска уже умели принимать USDT.
6. **Контент-маркетинг параллельно коду.** С Фазы 3 ведём Telegram-канал и снимаем демо-видео. На запуске уже будет аудитория.
7. **AI-ассистенты ускоряют разработку.** GLM-5.3 для системной логики и авторизации, MiniMax-M3 для UI/мультимодальных фич — оба через подписку.
8. **Ассистент без собеседника = вторая ЦА.** С Фазы 6 сразу делаем поддержку YouTube/подкастов/лекций — удваивает TAM.
9. **Подпись .exe обязательна.** Антивирусы (Defender, Kaspersky, Avast) ругаются на неподписанные Python-приложения. Покупаем EV Code Signing сертификат ($200–400/год).
10. **Никогда не работаем без чек-листа.** Каждый этап = чек-лист из `11_checklists.md`. Не переходим к следующей фазе, пока не закрыты критерии.
