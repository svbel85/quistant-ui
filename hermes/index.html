Куистант · Hermes

Пять точных копий design-system по наполнению (sidebar 260px + 8 секций со ВСЕМИ компонентами) в тёмной Hermes-эстетике с разными цветовыми палитрами.

📋 Что внутри каждого из 5 файлов

Layout: shell = sidebar 260px (sticky, со своим скроллом) + main (max-width 1100px, центрирован)

Sidebar: brand-логотип «К» (SVG-иконка + слово «Куистант»), иконка новой сессии, nav из 7 пунктов (Чат/Sessions/Skills/Models/Providers/Memory/Tools/Settings), секция «Текущая сессия» с 4 сессиями, footer с профилем

Hero: логотип 80px с градиентом + «Привет, Куистант» (gradient-text) + 4 action-pill (Начать созвон / Подключить папку / Найти в базе / Конспект лекции) + composer с textarea и toolbar (attach/voice/3 select/send)

Tokens: 10 swatches палитры (bg/bg-1/bg-2/bg-3/border/accent/live/solo/kb/danger) + 3 mode-индикатора (LIVE/SOLO/KEYBOARD) + 3 карточки (отступы/радиусы/тени) + типографика (Inter/Display/JetBrains Mono)

Buttons: 4 варианта (primary/secondary/ghost/danger) + 3 размера (32/40/44) + с иконками + 3 icon-only + loading

Inputs: 6 полей (text + search с иконкой + password + range с N + email с ошибкой + disabled HWID)

Controls: checkbox 4 состояния (off/on/indeterminate/disabled), switch 2 (off/on), 2 select (модель ИИ / тариф), 3 slider с прогрессом (громкость/прозрачность/whisper)

Chat-лента: system + other (интервьюер) + ai (с list из 4 пунктов + meta) + user (микрофон) + user-kb (клавиатура) + typing dots

Windows: 3 плавающих окна с drag-handle — Coding Helper (LIVE + N-slider + input), Lecture Notes (SOLO + FROZEN), Salary Coach

Feedback: 6 тегов (active/neutral/success/warn/danger/mono) + 3 тоста (ok/err/warn) + Modal Device Flow с кодом 482 917 + spinner 3 размера

Misc: Side Panel окон (3/5) + 2 Slice Card (#042/#043) + Empty State + Error State + сниппет кода whisper_loop с подсветкой
