# 🎨 ДИЗАЙН-СИСТЕМА И FIGMA-МАКЕТЫ «КУИСТАНТ» v2

> **Цель:** создать полную дизайн-систему и 12 экранов в Figma ДО начала кодинга. Без макетов код будет кривой, маркетингу нечего показать.

> **v2-фикс:** в `road_map_01` эта фаза дублировалась в `03_branding.md` (п.7.1) и `05_app_dev.md` (Шаг 0). В v2 — всё в **ОДНОМ** файле, без дублирования.

---

## 1. ЗАЧЕМ ОТДЕЛЬНАЯ ФАЗА

- **Без макетов ты не знаешь, как выглядит продукт.** Только экраны в Figma дают чёткое визуальное представление.
- **Дизайнер рисует один раз** → потом мы кодим по этим макетам, не дёргая дизайнера на каждой правке.
- **Макеты нужны маркетингу** (для лендинга, Telegram-канала, скриншотов, Product Hunt).
- **Инвесторы/друзья смотрят макеты**, а не код.

## 2. ДИЗАЙН-СИСТЕМА (определяется ДО макетов)

### Цветовая палитра (dark mode по умолчанию)

```yaml
background_primary:   "#0A0E1A"   # глубокий тёмно-синий
background_secondary: "#141825"   # карточки, окна
background_tertiary:  "#1E2335"   # ховер, активные элементы
accent_primary:       "#00D9FF"   # cyan — главные кнопки
accent_secondary:     "#39FF14"   # electric green — успех
warning:              "#FFD700"   # жёлтый
danger:               "#FF3366"   # красный
text_primary:         "#FFFFFF"
text_secondary:       "#A0A8B8"

# v2: новые цвета для маркировки режимов
mode_live:            "#FF6B6B"   # красноватый — идёт созвон
mode_solo:            "#9D4EDD"   # фиолетовый — ассистент без собеседника
mode_keyboard:        "#06D6A0"   # бирюзовый — текст с клавиатуры
```

### Шрифты

```yaml
ui_main:    "Inter"            # основной UI
ui_code:    "JetBrains Mono"   # для ID, хешей, кода
marketing:  "Space Grotesk"    # для заголовков в лендинге
```

### Размеры и отступы

```yaml
radius_sm:  4px
radius_md:  8px
radius_lg:  12px
radius_xl:  16px

spacing_xs: 4px
spacing_sm: 8px
spacing_md: 16px
spacing_lg: 24px

spacing_2xl: 48px

shadow_sm:  0 1px 2px rgba(0,0,0,0.2)
shadow_md:  0 4px 12px rgba(0,0,0,0.4)
shadow_lg:  0 8px 24px rgba(0,0,0,0.5)
```

### Минимальный набор инструментов

- **Dribbble/Behance** — для референсов

### Порядок

1. Создай файл «Куистант — UI» в Figma
2. Сделай 1 страницу «Дизайн-система» (цвета, шрифты, компоненты)
3. Сделай 1 страницу «Компоненты» (15+ переиспользуемых)
4. Сделай 1 страницу «Экраны» (все 12 экранов)
5. Добавь страницу «Состояния» (loading, error, empty, mode: live/solo)
6. Поделиться ссылкой со мной или с разработчиком
